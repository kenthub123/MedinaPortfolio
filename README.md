# Personal Portfolio

A responsive black-and-white portfolio built with React and Vite. It has Home, Projects, and Contact sections, a dark mode toggle that remembers your choice, and a live list of my latest GitHub repos.

## Technologies

React, Vite, JavaScript, CSS (Flexbox and Grid), GitHub REST API

## Features

- Responsive layout for mobile and desktop
- Smooth scrolling navigation
- Dark mode saved in localStorage
- Latest repos fetched from the GitHub API
- Contact form with a success alert (no email is sent)

## Setup

```bash
git clone https://github.com/kenthub123/portfolio.git
cd portfolio
npm install
npm run dev
```

Build for production with `npm run build`.
